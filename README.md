# Kashif Akbar — 3D Developer Portfolio

A premium, responsive personal developer portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Three.js (CDN)

## Run
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and the Three.js CDN.

## Included
- Interactive Three.js 3D hero object
- Floating 3D rings and particle field
- Mouse-follow parallax
- Glassmorphism UI
- 3D card tilt
- Scroll reveal animations
- Animated statistics
- Responsive mobile navigation
- Projects, skills, services, journey and contact sections
- Frontend contact-form validation
- Reduced-motion accessibility support

## Updating projects
Edit the project cards inside `index.html` under `#projects`. Replace titles, descriptions, tech tags and links as needed.

## Contact form
The form performs client-side validation and gives a clear success/error state. To receive submissions automatically, connect it later to a backend or form service.


Profile photo: `assets/kashif-profile.jpg` is used in the About Me section. Replace that file with your preferred photo (same filename) if you want to change it later. The About photo already has the existing 3D orbit rings and interactive mouse tilt.
